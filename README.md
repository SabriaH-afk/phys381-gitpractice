# phys381-git-practice

This repo has Python code and Jupyter notebooks for solving physics problems using computation. It includes topics like integration, differential equations, and simulations.

I looked at the Fourier.ipynb notebook. It shows how to use the Fourier Transform to analyze sound data. The code takes a signal from a file, turns it into frequencies, and plots the result. It also includes extra functions for cosine and sine transforms that are useful in physics and signal processing.
